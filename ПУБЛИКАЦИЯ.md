# Публикация ПР4–6

Команды выполняет Артём после просмотра файлов. Сейчас новые работы находятся в main без коммитов; отдельные ветки для сдачи папок не требуются. Каждая практика — отдельный коммит, затем один push.

```bash
cd /Users/artem/Desktop/tip-js-practices
git status --short
git add practice-04
git commit -m "Complete practice 04"
git add practice-05
git commit -m "Complete practice 05"
git add practice-06 README.md ПУБЛИКАЦИЯ.md
git commit -m "Complete practice 06 and update index"
git push origin main
```

Перед коммитом можно проверить состав через git diff --cached --stat. Файл КР2 находится в учебной папке и отправляется в СДО отдельно; он не добавлен в репозиторий. Публикация, отправка, защита и баллы — отдельные статусы.

Оставшиеся ручные пункты: ПР4 — полный обход кнопок клавиатурой при соответствующих настройках браузера; ПР6 — быстрые фильтры при замедленной сети DevTools. Они не выданы за выполненные. Основные автоматические проверки и реальные браузерные сценарии перечислены в README каждой работы.
