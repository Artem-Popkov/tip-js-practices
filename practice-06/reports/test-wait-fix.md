# Исправление ожидания в браузерном тесте преподавателя

Исходные checks/browser.checks.js и checks.html сохранены без изменений.
Отдельная версия checks/browser.wait-fixed.js подключена только на checks-wait-fixed.html.

В тесте создания задачи заменено только условие ожидания:

```diff
-await waitFor(() => requireNode(doc, '[data-task-id="35"]'), "Задача не появилась");
+await waitFor(() => doc.querySelector('[data-task-id="35"]'), "Задача не появилась");
```

requireNode синхронно бросает исключение до следующей итерации ожидания.
querySelector возвращает null, позволяя waitFor повторить проверку до 5 секунд.
Наличие карточки, текст, очищенная форма и total=13 проверяются как прежде.
Это исправление по инициативе помощника, а не отдельное требование методички.
Фактический исходный прогон в Safari: 13/14; прогон с исправлением: 14/14.
